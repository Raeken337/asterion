\# Asterion



A personal AI assistant with a celestial interface and selectable

conversational personalities.



\## Project status



Workspace setup. AI integration is not connected yet.



\## First-release goals



\- Basic chat interface

\- AI responses

\- Five selectable personality styles

\- Context within the active conversation

\- Shared behaviour boundaries

\- Clear loading and error messages

\- Minimal dark styling



\## Personality modes



\- Playful

\- Brooding

\- Clinical

\- Boomer

\- Creative / Celestial



\## Project structure



\- public/ — browser interface

\- docs/ — project documentation



\## Development approach



Build one feature at a time, check its behaviour, and commit working

milestones to Git.



\## Privacy



Never commit API keys, credentials, or private conversation data.
